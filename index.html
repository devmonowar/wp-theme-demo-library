How it works

Each theme reads its demo-library.json manifest from its folder above. The manifest lists demos with preview images; importing one downloads its content export, widgets, Customizer settings and images into the site.

This repository hosts only demo resources for my WordPress themes. No theme source code is stored here, and these files are not bundled into any theme package.
