Creative Studio

A small design and development studio: a homepage built from the theme's own sections, an about page with the team, services, a six-post journal with comments, and a contact page.

How to import

  1. Install and activate Kivora. No other plugin is required for the demo itself.
  2. Install One Click Demo Import — the free importer this demo is delivered through.
  3. Go to Appearance → Import Demo Data, find Creative Studio, and click Import. Pages, posts, comments, menus, widgets, theme settings and every image arrive together.

Import onto a fresh site where possible. The importer adds content rather than replacing it, so on a site that already has pages you will end up with both.

What the import creates

  • PAGES

    A homepage made of editable sections

    Hero, how-we-work, services, about, statistics, testimonials, latest writing, FAQ and a closing call to action — each one a block pattern from the theme, so every section can be reordered or removed in the ordinary page editor. Plus About with the team, a child page for the studio's approach, Services, Contact and a privacy policy.

  • JOURNAL

    Six posts, written like a real blog

    Three categories, tags, excerpts, featured images, one sticky post and a thread of comments — enough to see the blog grid, the single-post layout, the author box, related posts and the comment form with real content in them.

  • SETTINGS

    Menus, widgets and the theme's own options

    A main menu with a submenu and a footer menu, the sidebar and all four footer widget columns, the logo and site icon, and the theme settings the demo uses — sticky header, live search, right-hand sidebar — so the site you land on is the site in the screenshot.
