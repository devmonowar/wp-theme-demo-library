# Kivora demo image credits

Every photograph in these demos is **CC0 1.0** (public domain dedication), which
allows the redistribution this library depends on: the images are downloaded
onto the end user's site when they import a demo.

Found through [Openverse](https://openverse.org/), WordPress's own search for
openly licensed media, filtered to CC0 only.

The logo and site icon (`northline-studio-logo.png`, `northline-studio-icon.png`)
were drawn for this demo and carry the same GPL licence as the theme.
